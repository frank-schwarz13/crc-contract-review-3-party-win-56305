## About CRC Contract Auditor

CRC Contract Auditor supports legal counsel and clinical trial teams reviewing three-party CRC contracts. It applies a defined set of contract review rules, extracts and maps the roles described in an agreement, and presents findings in a format designed for compliance-oriented review.

The tool organizes findings by risk level and rule number, highlights the relevant contract context, and supports both standard and contract-adapted reporting. Because processing is performed on the client side with local data handling, the application is intended for browser-based review without requiring a separate processing service.

---

## Features

- Apply 24 professional rules for clinical trial contract review
- Classify findings across three risk levels
- Extract and map the roles involved in a three-party contract
- Aggregate identified risks by rule number
- Highlight contract context associated with detected risks
- Produce standard review reports
- Generate reports adapted to the reviewed contract
- Export results as Markdown
- Process contract data client-side with local handling

## FAQ

### Who is CRC Contract Auditor for?

The tool is intended for legal counsel and teams involved in clinical trial contract compliance review, particularly when examining three-party CRC agreements.

### What types of findings does it produce?

It identifies rule-based contract review findings, assigns them to one of three risk levels, groups them by rule number, and shows the surrounding contract context.

### Can I create different report formats?

Yes. The application supports a standard report format and a format adapted to the reviewed contract. Reports can be exported as Markdown.

### Are contracts sent to a remote service?

The available product profile describes the application as fully client-side, with local data handling. Review the project's implementation and your organization's requirements before processing sensitive documents.

### How do I get updates?

Use the hosted project link or check the repository for newer builds and release changes.

### The application does not open. What should I check?

Confirm that JavaScript is enabled, try a current browser, and run the project through a local static web server rather than relying on a restricted file URL.

### Where can I request support?

Open an issue in the repository with the browser, operating system, reproduction steps, and any relevant non-confidential details.
